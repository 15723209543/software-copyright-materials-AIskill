# 中国版权保护中心软件著作权登记 R11：填报项与附件核对

## 核心原则

该清单是给申请人复制到官网的**全面预填报草稿**，并不等同于登记机构页面的即时表单。官方在线申报界面、字数上限、附件格式、身份审核流程可能变化；申请人须登录中国版权保护中心当前系统亲自核对。部分事项只在特定情形下出现，多列不意味着每项都是无条件必填。

官网入口：https://www.ccopyright.com.cn/ ，常见登记业务是 R11 计算机软件著作权登记申请（参考2026年大学办理流程：https://kyc.sdufe.edu.cn/info/1077/5154.htm）。

## 从调用消息自动预填（第一优先级）

调用消息模板中要有独立“申请人/登记办理人”“著作权人”“联系人”三组；不能把 GitHub 邮箱、代码注释作者名、学生身份等自动当成申请信息。AI 从这些用户填写字段提取后写入 `project_analysis.json` → `official`，最终再生成官网下载填写用 MD。敏感证件号与手机号可不写入最终文件，而用 `【请直接在官网填写】` 提醒。

## 必须覆盖的字段类别

### A 申请资格及账号
官网注册/实名认证状态、业务类型、自然人/机构身份、权利人是否多人、本人申请或代理申请、代理授权状态。

### B 软件基本信息
完整中文软件名称（与材料一致）、简称（如有）、版本、软件分类和行业分类、软件作品说明（原创、修改等按页面选项）、升级或修改时的原登记号和修改说明、软件类型/应用领域。

### C 时间和发表
开发方式（独立/合作/委托/下达任务）、开发完成日期、是否发表、首次发表日期、首次发表国家/地区及城市、首次发表方式，发布日期应与实际公开行为一致；未发表不得编造日期。

### D 权利获得与范围
原始取得或继受取得（转让/继承/承受等）、全部权利或部分权利及具体权项、职务/非职务、合同或任务书、学校/单位内部权属审批（视具体单位要求）、合作著作权人名单及顺序。

### E 著作权人、联系人及代理人
权利人姓名或机构全称、身份类别、身份证件类型、证件号码/统一社会信用代码、国籍/注册地、通讯地址和邮编、电子邮箱、电话、联系人身份信息；申请人证件号不得按源码猜测，最好直接在官网填写而不保存到共享 MD。

### F 软件技术特点
硬件开发环境、运行硬件、开发操作系统、运行系统、开发工具/IDE及版本、软件运行支撑、编程语言及版本、框架和数据库、开发形态、软件**源程序量**（真实总行数，区别最终交存抽样页数）、主要功能、技术特点、适用领域、启动路径/运行方式。

### G 附件与签章
按实际官方页面准备 Word/PDF 鉴别材料、身份证明、法人或机构证明、联系人身份证明（如要求）、权属合同、委托/合作合同、任务书、授权或许可证明、原登记证明、单位归属材料、签名盖章和诚信承诺。2023年后已有无纸化办理安排，**不能把旧纸质递交流程当成唯一官方流程**。

### H 提交与补正
申请受理号、递交日期、审核状态、补正通知及补正期限、领取电子登记证书与登记号等为提交后再填信息。

## 2026年关于真实性的重点

2026-03-16 行业协会转发《中国版权保护中心关于共同维护计算机软件版权登记良好生态的通知》，强调申请人真实性及材料符合实际，故不得从模板编造一个“看起来完整”的软件功能清单，也不得冒用著作权人信息。
来源：https://www.ssia.org.cn/page65?article_id=2588

## 必须向申请人提醒

1. 技术部分可以由 AI 结合源码总结，但权利人、开发方式、完成日、首次发表日及其归属须本人确认。
2. 不要把用户的 GitHub 昵称、软件作者邮箱自动当作申请人真实姓名。
3. 软件版本号必须与本次实际提交的源程序对应，源码与说明书一致。
4. 提交前将每个官网字段的字数限制和附件格式当场核对；无法联网时标示“待官网实时核查”。
